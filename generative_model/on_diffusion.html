디퓨전 모델(Diffusion Models)의 수학적 본질과 매니폴드

수학적 유도로 이해하는 생성 모델의 시각적·직관적 비밀

Q1. 표준편차가 4인 가우시안 샘플을 만들려면 표준정규분포(표준편차 1) 샘플에 얼마를 곱해야 하나요?

정답은 4를 곱해야 합니다. 분산의 성질과 표준편차의 정의를 통해 쉽게 증명할 수 있습니다.

  • 수학적 증명: 표준정규분포를 따르는 변수 $X$의 분산이 $Var(X) = 1$일 때, 임의의 상수 $c$를 곱한 변수의 분산은 $Var(cX) = c^2 Var(X) = c^2$이 됩니다. 표준편차($\sigma$)는 분산에 루트를 씌운 값이므로 $\sigma_{cX} = \sqrt{c^2} = |c|$ 가 됩니다. 따라서 표준편차를 4로 만들려면 정확히 $c = 4$를 곱해야 합니다.
  • 직관적 이해: 분산은 편차를 제곱한 값이고, 표준편차는 원래 데이터의 실제 거리 단위를 나타냅니다. 데이터의 스케일을 4배 키우면 데이터 간의 물리적 거리가 4배 늘어나므로 표준편차도 정직하게 4배가 됩니다.

Q2. 디퓨전의 Forward 수식 $q(x_t \mid x_{t-1}) = \mathcal{N}(x_t ; \sqrt{1 - \beta_t}x_{t-1}, \beta_t I)$에서 $I$ 앞에는 왜 루트가 없나요?

수식이 완전히 올바르게 작성되었기 때문입니다. 가우시안 분포 표기법의 수학적 약속 때문입니다.

  • 통계학에서 가우시안 분포 $\mathcal{N}(\mu, \sigma^2)$를 표기할 때 두 번째 자리에는 표준편차가 아닌 분산(Variance)을 적기로 약속되어 있습니다. 따라서 분포 자체를 명시하는 위 식에서는 분산인 $\beta_t I$를 그대로 적는 것이 맞습니다.
  • 다만, 이 분포에서 실제로 샘플링을 수행하는 코드(Reparameterization Trick)로 변환할 때는 노이즈 $\epsilon$에 표준편차인 $\sqrt{\beta_t}$를 곱해 주게 됩니다.
실제 샘플링 식: $$x_t = \sqrt{1 - \beta_t}x_{t-1} + \sqrt{\beta_t}\epsilon$$

Q3. 임의의 실제 데이터셋($x_0$)을 가우시안 분포라고 가정하는 것이 타당한가요?

아닙니다. 실제 데이터($x_0$)는 가우시안 분포가 아닙니다. 디퓨전 모델은 데이터 자체를 가우시안이라고 가정하지 않습니다.

  • 가우시안 분포를 따르는 것은 데이터 자체가 아니라 단계를 넘어갈 때 더해지는 '노이즈를 가하는 방식(전이 확률, Transition)'입니다.
  • 초기 단계($t$가 작을 때)의 데이터는 원래의 복잡한 멀티모달 구조를 그대로 유지합니다. 그러나 이 가우시안 노이즈가 1000번 가량 누적되면서 마지막 단계($t=T$)에 이르면 중심극한정리에 의해 원래 데이터 구조가 완전히 지워지고 완벽한 표준 가우시안 노이즈 $\mathcal{N}(0, I)$로 수렴하게 됩니다.

Q4. Forward process 식을 굳이 복잡한 계수($\sqrt{1-\beta_t}$) 구조로 정의한 이유는 무엇인가요?

데이터 전체의 총 분산(Variance)을 시작부터 끝까지 항상 '1'로 일정하게 유지(Variance-Preserving)하기 위해서입니다.

  • 입력 데이터 $x_0$의 분산을 1로 전처리했다고 가정했을 때, 앞서 배운 분산의 선형 결합 공식을 대입하면 다음과 같이 총 분산이 보존됩니다:
    $Var(x_1) = (\sqrt{1-\beta_1})^2 Var(x_0) + (\sqrt{\beta_1})^2 Var(\epsilon) = (1-\beta_1)\cdot 1 + \beta_1\cdot 1 = 1$
  • 이유: 데이터의 외형적 크기(스케일)를 일정하게 묶어놓아야 역과정을 학습하는 딥러닝 신경망(U-Net)이 혼란을 겪지 않으며, 마지막 $x_T$ 단계에서 군더더기 없는 완벽한 표준 가우시안 노이즈를 코드로 쉽게 생성($\text{torch.randn}$)할 수 있기 때문입니다.

Q5. VAE나 GAN처럼 병목 구조가 없는데, 왜 GAN과 디퓨전은 의미 있는 매니폴드(Manifold)를 배우나요?

명시적인 압축 구조가 없더라도 연속성 제약과 확률 공간의 최적화 과정을 통해 정교한 데이터 매니폴드가 형성됩니다.

  • GAN: 뉴럴 네트워크는 연속 함수입니다. 가짜 노이즈 공간($Z$)에서 가까운 두 점은 실제 이미지 공간($X$)에서도 가까워야 합니다. 판별기($D$)에게 걸리지 않고 가짜 이미지 사이를 자연스럽게 이어 붙이려면, 생성기($G$)는 실제 데이터가 존재하는 얇은 매니폴드 선상을 따라 걷는 '최단의 지름길 매핑'을 개척할 수밖에 없습니다.
  • Diffusion: 디퓨전 모델이 예측하는 노이즈는 수학적으로 데이터 확률 밀도의 기울기 벡터인 스코어(Score, $\nabla_x \log p(x)$)를 나타냅니다. 공간 전체에서 고밀도 영역(데이터 매니폴드 중심축)을 향하도록 촘촘하게 새겨진 '인력 벡터장'을 통째로 학습하기 때문에, 노이즈 상태에서의 미세한 움직임이 역과정을 거치며 부드러운 매니폴드 이동으로 번역됩니다.
모델 매니폴드 형성의 근본 원리
PCA 데이터 분산이 최대인 핵심 축을 직접 수학적으로 투영
VAE 저차원 병목(Bottleneck) 구조를 강제하여 잡음을 유실시킴
GAN 판별기의 단속을 피해 진짜 데이터 영역 안에서만 이동하는 연속적인 매핑 형성
Diffusion 공간 전체에 실제 데이터 축으로 수렴하는 부드러운 인력 벡터장(Score) 조각

Q6. 손실 함수 $L_{simple} = \mathbb{E} [\|\epsilon - \epsilon_\theta(x_t, t)\|^2]$는 왜 단계별($t$와 $t-1$) 차이가 아니라 누적 노이즈 $\epsilon$을 맞추나요?

원래 디퓨전의 철학은 '바로 한 단계 전($t-1$)의 평균을 맞추는 것'이 맞습니다. 하지만 이를 수학적으로 증명 및 전개하는 과정에서 놀라운 동치 관계가 증명되었습니다.

  1. 원래의 목적식은 이론적 실제 평균 $\mu_t$와 모델의 예측 평균 $\mu_\theta$의 차이를 줄이는 $\| \mu_t - \mu_\theta \|^2$ 입니다.
  2. 여기에 여러 단계를 건너뛰는 공식인 $x_0 = \frac{1}{\sqrt{\bar{\alpha}_t}} \left( x_t - \sqrt{1 - \bar{\alpha}_t}\epsilon \right)$를 대입하여 식을 정리합니다.
  3. 그 결과 복잡한 계수와 변수들이 서로 상쇄되며 내부 알맹이인 $\mathbb{E} [\|\epsilon - \epsilon_\theta\|^2]$만 남게 됩니다.

즉, 한 단계 전으로 돌아가기 위해 깎아내야 할 미세한 조각을 찾는 행위는, 현재 $x_t$에 스며있는 전체 누적 노이즈 $\epsilon$의 형태를 파악하는 것과 수학적으로 100% 완벽하게 동일한 작업입니다. 컴퓨터에게 평균 계산 규칙을 학습시키는 것보다 순수한 가우시안 노이즈 자체를 타겟으로 주는 것이 학습 효율과 안정성 면에서 훨씬 우수하기 때문에 이 식이 최종 표준 손실 함수가 되었습니다.
