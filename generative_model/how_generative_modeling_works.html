생성 모델은 어떻게 데이터를 외우지 않고 다양체(Manifold)를 배우는가?

들어가는 글: VAE, Diffusion, GAN 등의 생성 모델은 고차원 데이터셋을 정규분포(잠재 공간)로 매핑했다가 되돌리는 과정을 거칩니다. 그런데 왜 모델은 훈련 데이터를 그대로 외우지(Overfitting) 않고, '비슷하지만 새로운' 데이터를 만들어낼까요? 다양체 가설과 확률론의 관점에서 그 핵심 이유를 묻고 답합니다.

Q1. 신경망이 훈련 데이터만 완벽하게 외워버리지 않고, 새로운 데이터를 '생성'해내는 수학적 원리는 무엇인가요?

A1. 신경망의 연속성과 확률 밀도의 누수(Leakage) 때문입니다.

  1. 차원의 저주와 연속 함수: 784차원(MNIST) 공간에서 훈련 데이터는 고작 몇 만 개의 ‘점(Dirac delta)’에 불과합니다. 하지만 신경망은 연속적이고 미분 가능한 함수입니다. 특정 데이터 점 위치에서만 확률을 무한대로 솟구치게 만들 수 없으므로, 데이터 주변 영역으로 확률 밀도가 부드럽게 퍼지는 밀도 누수(Leakage)가 필연적으로 발생합니다. 이 누수된 공간이 바로 생성 데이터의 영역입니다.
  2. 잠재 공간의 보간(Interpolation): 가우시안 정규분포 공간(\(Z\))은 촘촘하게 채워진 연속 공간입니다. 연속 함수인 디코더는 잠재 공간의 연속적인 경로를 데이터 다양체(\(\mathcal{M}\)) 위의 연속적인 경로로 매핑합니다. 따라서 두 잠재 벡터를 잇는 중간 지점들은 다양체 위에서 자연스럽게 섞인 '새로운 데이터'로 복원됩니다.
  3. KL 발산(MLE)의 제약: 최대우도추정(MLE)은 훈련 데이터 주변의 확률을 0으로 만드는 순간, 오차가 무한대로 발산하는 특성(Zero-avoiding)을 가집니다. 따라서 모델은 손실을 줄이기 위해 데이터 점들을 아우르는 가장 부드럽고 넓은 곡면(Manifold)을 찾아 확률을 안전하게 채우는 방향으로 최적화됩니다.

Q2. ReLU 활성화 함수는 미분이 불가능하고 꺾여있는데, 어떻게 미분 가능하고 연속적인 다양체를 배우나요? 또한, 데이터 점을 지나는 수많은 엉뚱한 경로 중 '진짜 다양체'를 찾는 이유는 무엇인가요?

A2. 조각 선형 다양체(Piecewise Linear Manifold)의 형성 및 경사하강법(SGD)의 내재적 편향 덕분입니다.

  1. ReLU의 연속성: ReLU는 \(x=0\)에서 미분은 불가능하지만 끊어지지 않는 연속 함수입니다. 연속 함수의 합성 역시 연속 함수이므로, ReLU 네트워크가 만드는 공간은 부드러운 곡면은 아닐지라도, 수많은 평면 조각들이 촘촘하게 꺾여서 연결된 다면체 형태의 다양체를 형성합니다.
  2. 오캄의 면도날 (Implicit Regularization): SGD로 신경망을 최적화할 때, 네트워크는 파라미터 공간에서 가장 부드럽고 곡률이 낮은(Low-curvature) 함수를 먼저 선택하는 강력한 내재적 편향을 가집니다. 데이터 점들을 급격하게 꺾어가며 억지로 외우는 복잡한 경로는 기울기 폭발을 일으키므로 SGD가 기하학적으로 배제합니다.

Q3. MLE 기반 모델은 그렇다 치고, GAN이 그럴듯한 다양체를 잘 근사하는 것도 같은 원리인가요?

A3. 아닙니다. GAN은 완전히 반대되는 방향성(Reverse KL / JSD)을 가집니다.

  • MLE 기반 모델 (Forward KL): 데이터 전체 분포를 안전하게 감싸려고 합니다(Mean-seeking). 다양체 전체의 부피를 포착하므로 안정적이지만 결과물이 흐릿합니다.
  • GAN (Reverse KL 성향): 진짜 데이터가 없는 곳에 확률을 배정하면 극심한 페널티를 받습니다(Mode-seeking). 따라서 다양체 전체를 배우기보다는, 판별기를 속일 수 있는 가장 확실한 핵심 골격(Mode) 위에만 확률 밀도를 집중시킵니다. GAN이 선명한 이미지를 뽑아내면서도 고질적인 모드 붕괴(Mode Collapse)를 겪는 기하학적 이유입니다.

Q4. 만약 활성화 함수를 완전히 빼고, 인코더와 디코더를 각각 1층의 선형 레이어로만 구성해도 무언가 의미 있는 다양체를 배우나요?

A4. 네, 주성분 분석(PCA)과 수학적으로 동일한 '평평한 선형 다양체'를 배웁니다.

  • 선형 오토인코더(Linear AE)의 본질: 활성화 함수가 없는 1층의 디코더 행렬은 고차원 공간을 가로지르는 \(d\)차원의 평평한 초평면(Hyperplane)을 정의합니다. 1989년 Baldi & Hornik의 연구에 따라, 선형 오토인코더의 최적 해가 정사영하는 부분공간은 PCA가 찾는 주성분 공간과 완벽히 일치함이 증명되었습니다.
특성 PCA (주성분 분석) 선형 오토인코더 (Linear AE)
기저의 직교성 주성분 벡터들이 서로 직교함 (\(W^T W = I\)) 기저 벡터들이 직교할 필요가 없음 (Non-orthogonal)
축의 순서 고유값 크기 순으로 고유한 순서가 정해짐 공간 내에서 기저들이 회전되어 있어 순서가 없음
수학적 해 SVD를 통한 유일한(Unique) 해 경사하강법으로 도달하며, 무수히 많은 동치 해 존재

🛠️ 실습 코드: PCA vs 선형 AE vs 비선형 AE 격자 탐색

세 모델이 데이터 공간을 어떻게 다르게 해석하는지 확인하기 위해, 2차원 잠재 공간의 \([-10, 10]\) 구간을 \(10 \times 10\) 격자로 샘플링하여 하나의 \(280 \times 280\) 행렬 이미지로 복원·비교하는 파이토치 핵심 코드입니다.

import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim
from torchvision import datasets, transforms
from torch.utils.data import DataLoader
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# 1. 데이터 로드 및 784차원 평탄화
transform = transforms.Compose([transforms.ToTensor(), transforms.Lambda(lambda x: x.view(-1))])
train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)
X_train_tensor, _ = next(iter(DataLoader(train_dataset, batch_size=len(train_dataset))))
X_train = X_train_tensor.numpy()

# 2. 잠재 공간 격자 생성 (-10 ~ 10)
grid_x, grid_y = np.linspace(-10, 10, 10), np.linspace(-10, 10, 10)
grid_latent = np.array([[x, y] for y in grid_y[::-1] for x in grid_x], dtype=np.float32)

# 3. 모델 1: PCA 복원
pca = PCA(n_components=2).fit(X_train)
images_pca = pca.inverse_transform(grid_latent)

# 4. 오토인코더 구조 정의 및 학습 함수
class Autoencoder(nn.Module):
    def __init__(self, use_nonlinear=False):
        super().__init__()
        if use_nonlinear:
            self.encoder = nn.Sequential(nn.Linear(784, 128), nn.ReLU(), nn.Linear(128, 2))
            self.decoder = nn.Sequential(nn.Linear(2, 128), nn.ReLU(), nn.Linear(128, 784), nn.Sigmoid())
        else:
            self.encoder = nn.Linear(784, 2, bias=False)
            self.decoder = nn.Linear(2, 784, bias=False)
    def forward(self, x): return self.decoder(self.encoder(x))

def train_ae(model, data):
    loader = DataLoader(data, batch_size=256, shuffle=True)
    optimizer = optim.Adam(model.parameters(), lr=0.002)
    for epoch in range(15):
        for batch in loader:
            optimizer.zero_grad()
            loss = nn.MSELoss()(model(batch), batch)
            loss.backward(); optimizer.step()
    return model

# 5. 선형 및 비선형 AE 학습 및 복원
linear_ae = train_ae(Autoencoder(False), X_train_tensor)
nonlinear_ae = train_ae(Autoencoder(True), X_train_tensor)

with torch.no_grad():
    grid_tensor = torch.tensor(grid_latent)
    images_linear = linear_ae.decoder(grid_tensor).numpy()
    images_nonlinear = nonlinear_ae.decoder(grid_tensor).numpy()

# 6. 280x280 단일 행렬로 시각화하는 함수
def plot_large_matrix(images, title):
    grid_reshaped = images.reshape(10, 10, 28, 28)
    grid_transposed = grid_reshaped.transpose(0, 2, 1, 3)
    large_matrix = np.clip(grid_transposed.reshape(280, 280), 0, 1)
    
    plt.figure(figsize=(5, 5))
    plt.imshow(large_matrix, cmap='gray')
    plt.title(title, fontsize=12, fontweight='bold', pad=10)
    plt.axis('off'); plt.tight_layout(); plt.show()

plot_large_matrix(images_pca, "1. PCA Subspace")
plot_large_matrix(images_linear, "2. Linear AE Subspace")
plot_large_matrix(images_nonlinear, "3. Non-linear AE Manifold")
맺음말: 결과적으로 생성 모델은 수치적 연속성, 정보이론적 제약, SGD의 기하학적 편향이 융합되어 데이터를 통째로 암기하는 대신 데이터를 지탱하는 부드러운 하위 차원의 매니폴드를 선택하게 됩니다. 활성화 함수는 이 평평한 초평면을 곡면으로 구부려 진짜 현실 데이터와 유사한 고차원 비선형 공간을 모사할 수 있게 유도하는 핵심 열쇠입니다.
